This folder contains the scripts to generate the data required for the figure plotting (i.e. bore_stats and djl_stats) from the raw input, which in this case is the library of bore arrivals (currently mooring_data_byevent_v1p3.mat). The code is written in Python (v3.10.12) for Jupyter Notebooks, using numpy (v3.7.2), matplotlib (v1.25.2), scipy and gsw. 

process.ipynb generates bore_stats.npz and saves inputs for the python script run_wave_speeds.py, which, when run separately, will calculate linear and nonlinear wave speeds for each arrival using the 30-minute pre-bore stratification and save these to djl_stats.npz. It requires the mooring dataset to run. Generating bore_stats takes a couple of minutes, I have found that run_wave_speeds.py takes about 30 minutes - 1hr when run on the entire dataset of mode-1 arrivals.
